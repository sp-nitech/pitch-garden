pitch-garden documentation
==========================

`pitch-garden <https://github.com/takenori-y/pitch-garden>`_ provides a unified
interface to various pitch (F0) trackers and integrates their outputs by voting.
See the `README <https://github.com/takenori-y/pitch-garden#readme>`_ for the
installation and the usage.
